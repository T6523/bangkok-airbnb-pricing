About the project

Predicts nightly Airbnb prices in Bangkok. DuckDB SQL does the cleaning and feature engineering; LightGBM, XGBoost and CatBoost (tuned with Optuna) and a three-model ensemble are compared against a linear baseline.

Data
Inside Airbnb Bangkok, scraped 2026-09-22 (CC BY 4.0). 30,922 raw listings, 28,092 modelled, asking prices from 361 to 18,541 THB.
Grouped split
Train and test are split by host, so no host appears on both sides.
Best model
Ensemble of the three tuned boosters, test MAE 666 THB (95% CI 599–737), against 804 THB (731–883) for linear regression, on 1,426 held-out hosts. Paired bootstrap difference: 138 THB (CI 53–203).
What drives price
Listing size first (shuffling it adds 592 THB of MAE), then location (172), stay rules (141) and amenities (90).
This page
The demo is a smaller 7-input LightGBM, less accurate than the ensemble. Its 80% range comes from out-of-fold errors on the training hosts.
Limits
One snapshot, asking prices rather than paid prices, and importance describes the model, not causes.
